# Contexto de `erros`

Páginas de resposta para situações em que o usuário não consegue continuar normalmente:

- `403.html`: acesso não autorizado à área solicitada.
- `404.html`: página não encontrada.
- `500.html`: erro interno do servidor.
- `sessao_expirada.html`: sessão expirada; orienta o usuário a entrar novamente.

As páginas seguem a identidade visual do JEVES, oferecem caminhos de retorno à navegação e incluem scripts locais para interações como menu e animações. A configuração do servidor para apresentar cada página no status HTTP correspondente é feita fora destes arquivos HTML.
